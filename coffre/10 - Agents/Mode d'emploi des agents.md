# Mode d'emploi des agents

Ton Laurisverse est organisé comme une entreprise : toi au centre (CEO), un Chief of Staff qui reçoit chaque demande, un board de garde-fous, et cinq directions (Études, Marchés, Croq, Finances perso, Tech) avec leurs postes.

## Où le voir

Laurisverse > panneau de droite > Vue > **Organigramme**. Clique un agent pour ouvrir sa fiche : rôle, modèle, outils, avec qui il travaille, ses derniers passages, et le bouton **Copier l'appel**.

## Comment convoquer un agent

1. Ouvre sa fiche dans l'organigramme et clique **Copier l'appel**.
2. Colle la phrase dans le projet Claude, puis écris ta demande à la suite.

## Comment ajouter ou modifier un agent

- Une fiche = un fichier de ce dossier. Copie une fiche existante, change le nom et les champs, relance le Laurisverse.
- Les fiches marquées `statut: brouillon` attendent tes précisions (dates de contrôles, intitulés des cours, projet Croq).
- L'en-tête suit le format des sous-agents de Claude Code (name, description, tools, model) : le dossier peut être copié tel quel dans un dossier `.claude/agents/` si tu utilises Claude Code un jour.
