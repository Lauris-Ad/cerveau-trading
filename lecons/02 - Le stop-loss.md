# 📖 Le stop-loss

## 🧩 L'idée en une phrase
Un ordre de vente automatique, fixé **avant** d'entrer, qui limite ma perte maximale : la ceinture de sécurité du trader.

## 📚 L'essentiel
- **Les pertes ne se rattrapent pas symétriquement :**

| Perte | Gain nécessaire pour revenir à zéro |
|---|---|
| −10 % | +11 % |
| −25 % | +33 % |
| −50 % | +100 % |
| −75 % | +300 % |
| −90 % | +900 % |

- **Stop-market :** vend au marché au niveau choisi. Sortie garantie, prix non garanti (slippage). ✅ Pour débuter.
- **Stop-limit :** deux prix (déclencheur + limite). Si le prix chute trop vite, l'ordre peut **ne jamais s'exécuter**.
- **Trailing stop :** suit le prix à la hausse, jamais à la baisse. Protège les gains, mais peut faire sortir trop tôt.
- **Break-even :** remonter son stop au prix d'achat quand le trade est en gain.
- Avec un stop, je perds le **risque** (ex. 10 €). Sans stop, je peux perdre toute la **position**.
- Sur un token sans liquidité ou en cas de rug pull, aucun stop ne protège.

## ✅ Checklist
- [ ] Je connais mon stop **avant** d'entrer
- [ ] Je le place **immédiatement**
- [ ] Perte possible ≈ 1 % de mon capital maximum
- [ ] Je ne le descends **jamais**, je peux seulement le monter
- [ ] Je juge mes trades sur le **respect de mes règles**, pas sur le résultat
