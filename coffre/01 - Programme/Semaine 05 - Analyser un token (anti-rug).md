# Semaine 05 : Analyser un token (anti-rug)

## 🎯 Objectifs
- Connaître les types d'arnaques : rug pull, honeypot, mint caché, taxes abusives, dump des créateurs.
- Savoir vérifier un token avec les wallets qui le détiennent.
- Construire **ma** checklist anti-rug, et l'appliquer à 3 tokens.
