# 💻 Code

Ce dossier accueillera les **notes** sur mes scripts Python à partir de la semaine 3 : ce que fait chaque script, comment le lancer, ce que j'ai appris.

> Le code lui-même ira dans un dossier séparé (par exemple `Documents/trading-bot`), **en dehors** de ce coffre, avec le fichier `.env` qui contient les clés API. Ainsi, aucun secret ne se retrouve dans Obsidian.

## Scripts prévus
| Semaine | Script | Rôle |
|---|---|---|
| 3 | `position.py` | Calculer une taille de position |
| 4 | `maj_wallets.py` | Mettre à jour les fiches wallets via l'API Etherscan |
| 6 | `historique.py` | Historique des transactions d'un wallet |
| 7 | `watchlist.py` | Mettre à jour tous les wallets suivis |
| 8 | `bot_telegram.py` | Envoyer des alertes sur Telegram |
| 10 | `marche.py` | Bougies, amplitude, ATR avec ccxt |
| 11 | `backtest.py` | Tester une stratégie sur l'historique |
